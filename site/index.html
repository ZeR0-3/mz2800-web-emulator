MZ-2800 Web Emulator

Common Source Code Project (武田 利也 氏 / K.Ohta 氏) の MZ-2800 を WebAssembly 化
ROMなしでも起動できます

右の「ROM」に IPL.ROM と KANJI.ROM を選ぶか、このページへドラッグ&ドロップしてください。ROMはこのブラウザの中にだけ保存され、どこにも送信されません。

FD HD -- 画面をクリックするとキー入力が有効になります

ROM(各自で用意・省略可)

DICT.ROM は任意(辞書ROM)。選んだROMはこのブラウザの IndexedDB に保存されます。IPL.ROM を選ばない場合は内蔵の疑似IPLで起動します(FD/HDDからのブートとFreeDOS-MZ2800向けの最小BIOS。漢字・カナ表示や、実機BIOSの機能を前提にするソフトは動きません)。

自動保存はこのブラウザの中だけです(ブラウザのデータを消すと失われます)。確実に残すには「保存」でダウンロードしてください。

操作

キー配列は日本語(JIS)キーボードの物理位置に対応。半角/全角=かな漢字, 変換/無変換, PageUp/Down=F13/F14。
